# Last Chair — web app

Next.js + React Three Fiber + Zustand playable slice for **Last Chair**.

## Run

```bash
npm install
npm run dev
```

- `/` — marketing home  
- `/play` — Dutch Hill day/night loop (primary)

## Stack

- Next.js (App Router) · React · TypeScript  
- `@react-three/fiber` + `drei` + Three.js  
- Zustand (persisted local save) · Tailwind
